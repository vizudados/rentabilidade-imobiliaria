# Rentabilidade Imobiliária — mídias da capa

Ativos visuais da capa do portfólio Vizu Dados, preparados para uso por HTTPS no Power BI HTML Content.

O relatório e suas bases não fazem parte deste repositório. Os números permanecem dinâmicos no Power BI e não são gravados nos vídeos.

## Créditos

Foto de referência externa: [Bairro do Bessa em João Pessoa](https://commons.wikimedia.org/wiki/File:Bairro_do_Bessa_em-_Jo%C3%A3o_Pessoa.jpg), TiagoLubiana, 11/01/2022, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

As cenas de vídeo são adaptações geradas com Seedance a partir dessa referência; não são filmagens documentais nem uma representação garantida do skyline atual. O ambiente do apartamento é gerado. A composição gráfica, maquete vetorial e animações foram criadas para este projeto com HyperFrames.

Os arquivos finais são versionados por conteúdo. O manifesto registra duração, resolução e hash de cada ativo publicado.
